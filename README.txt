KID DRACULA - LEVEL SELECT v1.0
Game Boy ROM hack by wavedout
Released September 24, 2026

OVERVIEW
--------
Kid Dracula - Level Select expands the title menu while preserving the
original START and PASSWORD modes:

  START
  PASSWORD
  LEVEL SELECT
  EXTRA

LEVEL SELECT
------------
Choose any of the game's eight stages. Each stage is identified by a concise
descriptive name:

  1. CASTLE
  2. FOREST
  3. CLOUDS
  4. PIRATE SHIP
  5. SPACE LIFT
  6. VOLCANO
  7. ROBOT MINES
  8. GARAMOTH

The Level Select menu also provides these options:

- LIVES: 01, 03, 05, 09, or 99
- SPELLS: DEFAULT or ALL

DEFAULT provides the spells normally available at the selected point in the
game. ALL enables all seven legitimate spells.

Level Select controls:

- Up/Down: Choose a setting
- Left/Right: Change its value
- A on START: Begin the selected stage
- Start anywhere: Begin immediately with the current settings
- B: Return to the title menu

EXTRA
-----
EXTRA provides visible access to the game's MUSIC TEST and MINI GAMES modes.

- In MUSIC TEST, B returns to EXTRA.
- In MINI GAMES, choose NONE to return to EXTRA.
- On the EXTRA menu, B returns to the title menu.

Mini-game coins and extra lives do not transfer to a subsequently started main
game; starting the game resets those values as it does in the original game.

PASSWORDS
---------
The original password system is retained. The game still supplies passwords
after a game over, and B returns from password entry to the title menu.

NOTES
-----
- The stage subtitles are descriptive labels created for this hack; the
  original game does not provide official stage names.
- LIVES counts the current attempt. The in-game P counter displays reserve
  lives, so it shows one less (for example, LIVES 03 appears as P-02).

  owners. This fan-made patch is distributed without a game ROM.
